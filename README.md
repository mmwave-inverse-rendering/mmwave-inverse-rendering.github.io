# mmIR project page

Project page for **mmIR: Frequency-Space Inverse Rendering for 3D Millimeter-Wave Radar ADC Synthesis** (ECCV 2026).

- Authors: Adnan Armouti, Yixuan Gao, Rajalakshmi Nandakumar (Cornell Tech)
- Live: https://mmwave-inverse-rendering.github.io/

Minimal static landing page (title, venue, authors, and coming-soon links). No build step:

```bash
python -m http.server 8000 --directory .   # then visit http://localhost:8000
```

## Branches
- `main` — **public** branch. Paper / Supplementary / Code are "coming soon" placeholders. This is the only branch published to GitHub Pages.
- `full` — **local-only** branch with bundled PDFs and live Paper/Supplementary links. For local preview only; do **not** push or publish.
